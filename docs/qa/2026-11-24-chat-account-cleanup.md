# Google Chat 계정 정리

- `확인할 대화`에서 Google 계정 이메일과 모든 프로젝트의 연결 공간 수를 확인한다. 연결된 공간이 없는 계정만 확인창을 거쳐 해제할 수 있다. 현재 프로젝트가 사용하는 계정을 우선 선택하며, 해당 계정이 만료되면 다른 계정을 자동 대체하지 않는다.
- 계정 삭제 요청은 기존 소유자·버전 검사 뒤 계정 행을 잠근다. 연결된 공간이 있으면 409를 반환하고 아무 것도 지우지 않는다. 미사용 연결만 로컬에서 제거한다. Google 제공 권한 취소, Gmail·일정 변경, 업무 데이터 백필 또는 마이그레이션은 없다.
- 조사 당시 최신 완료 보고 승인 5건은 개발방 Chat 200 및 운영방 답글 성공이었다. 같은 일감의 ITSM 실패는 별도 기록이다. 홈의 합산 `반영 실패`를 완료 Chat 실패와 동일하게 해석하지 않는다. 조사 중 실제 전송·삭제·재승인은 하지 않았다.
- 격리 PostgreSQL 59개 시나리오 통과. 두 프로젝트에서 사용하는 계정 보호, 미사용 계정 제거, 다른 소유자·오래된 버전 거부 검증 포함. API/Storage 단위 240개 및 서비스 Clippy 통과.
- 프런트 단위 569개, 타입 검사와 빌드 통과. Chrome headless 1280px·390px·320px에서 44px 클릭 영역, 가로 넘침 없음, 취소·해제·복귀 포커스 확인. 지연된 409 응답에서 진행 중 중복 방지와 복구 문구 확인. 전화 폭은 화면 아래쪽의 짧은 확인창을 사용한다.
- 설계 및 공개 문구 스캔은 해당 대상에서 확인했다. 전체 작업공간의 기존 정적 검사 지적과 별도의 활성 run은 수정하지 않았다.
- 운영 서버나 설치 앱을 변경하지 않았다. 반영하려면 API 및 앱 화면의 업데이트가 필요하다.
