# UX Writing Run Manifest

Status: handoff

## Target Files

- `apps/desktop/src/components/HomeInflowReview.tsx`
- `apps/desktop/src/copy/projects.ts`

## Writing Contract

- WRITING.md reviewed: 해요체, 짧은 행동 안내
- TERMS.md reviewed: 기존 할 일/업무 요청 용어 유지
- Locale: ko
- Product concept: 들어온 요청을 기존 목록·상세 화면에서 분류
- Tone: clear before clever

## Copy Review

- Korean: 탭은 새 업무 요청/기존 일감 업데이트, 좁은 화면은 새 요청/기존 일감
- English: 새 영어 공개 문구 없음
- Terms: 내부 용어 추가 없음
- Error messages: 기존 오류 문구 유지
- Buttons and CTAs: 탭으로 분류, 기존 실제 처리 버튼 유지
- Empty/loading/success states: 빈 탭은 다른 탭에서 확인할 행동 안내
- Naming: 별도 카드가 아닌 동일 화면의 보기 기준

## Rewrites

| Before | After | Reason |
| --- | --- | --- |
| 별도의 새 업무/기존 일감 카드 | 하나의 영역 안 탭 | 목록·상세의 너비와 집중도 유지 |

## Exceptions

승인 예외 없음. 기존 파일 자동 문구 검사 오탐은 새 문구 추출 및 계약 검토로 분리 확인한다.
